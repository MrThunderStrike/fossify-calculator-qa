# Installation Testing Evidence

This folder contains nine screenshots documenting installation-related testing of Fossify Calculator on Android 16 and Android 17.

The evidence includes APK availability, ADB uninstall and reinstall results, package verification, application launch, and emulator observations.

Some screenshots contain redacted local identifiers. The emulator home-screen screenshot demonstrates application icon visibility but does not independently prove that the ADB installation command succeeded.

APK authenticity and upgrade behavior were not verified.
